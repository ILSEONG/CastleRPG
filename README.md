# CastleRPG PC(윈도우) 버전

빌드: main ec79edd (Windows x86_64, release). 온라인 서버(castlerpg-api.onrender.com)에 연결됩니다.

1. CastleRPG-windows.zip을 받아 압축을 풉니다.
2. CastleRPG.exe를 더블클릭합니다.
3. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다(서명 안 된 개발 빌드라서 뜹니다).
4. 로그인 화면에서 Google을 누르면 브라우저가 열립니다. 폰과 같은 Google 계정으로 로그인하면 같은 진행 상황으로 들어갑니다.
