# CastleRPG 설치 파일(APK)

안드로이드 폰에 직접 설치하는 테스트용 빌드입니다. 코드는 이 브랜치에 없습니다(소스: `main`).

- 파일: `CastleRPG.apk` (arm64 폰용, 약 55MB)
- 빌드 기준 커밋: `750ab5f` (main — 영웅 36명이 상세 화면 받침 가운데에 서도록 맞춤 + 성문 위 동·서·남·북 글자 없앰 + 길드 창설 비용 골드 500,000 + 스킬 타격감 강화(타격 섬광·화면 흔들림·히트스톱·피격 번쩍임) + 길드 시스템(하단 [길드] 탭: 가입·출석·기부·길드 버프·길드 보스·길드 상점) + 영웅 36명 Meshy 모델 + 소환수 8종·던전 적 3종 Meshy 모델 + 스킬 이펙트 고퀄리티화 + 액티브 스킬 발동 모션 + UI 테두리 연하게 + 캐릭터 외곽선 없앰 + 영웅 레벨업 능력치 상승폭 0.7배 + 영웅 텍스처 손실 압축으로 APK 크기 축소)
  영웅 텍스처를 손실 압축으로 바꿔 크기를 100MB에서 55MB로 줄였습니다.
- 서명: 테스트용 키 — 스토어 배포용이 아닙니다. `f550043` 빌드와 같은 키라 그 위에 바로 덮어 설치됩니다(`11f2b3a` 이전 빌드가 깔려 있으면 지우고 설치).
- 서버 주소가 비어 있어 **오프라인 모드**로 돕니다(진행은 폰에 저장).

## 설치

1. 폰 브라우저로 GitHub에 로그인한 뒤 이 브랜치의 `CastleRPG.apk` → 다운로드(Download raw file).
2. 다운로드한 파일을 엽니다. "출처를 알 수 없는 앱" 경고가 나오면 그 브라우저(또는 내 파일 앱)에 설치 허용을 켭니다.
3. 설치 → 실행.

예전에 다른 키로 서명된 CastleRPG가 깔려 있으면 "앱이 설치되지 않았습니다"가 뜰 수 있습니다 — 기존 앱을 지우고 다시 설치하세요(저장 데이터도 지워집니다).
