# 게임 문구(다국어 표)

2026-10-14 사용자 요청: "모든 메시지 라벨을 다국어로 관리해줘, DB에 다국어 테이블을 만들고 일단 한국어만 값 채워줘".

## 구조

- **DB `texts` 표** (마이그레이션 `049_texts.sql`): `key` · `ko` · `en` · `ja` · `zh` · `note`(쓰는 곳). 언어 칸이 비면 한국어로 보인다.
- **원본 파일 `data/texts.csv`**: 다른 기획 표처럼 `npm --prefix server run neon:seed`가 DB에 넣는다(CSV에 없는 키는 DB에서도 지운다).
  - 따옴표 CSV(쉼표가 든 칸은 `"…"`), 값 안의 줄바꿈은 `\n`, 역슬래시는 `\\`로 적는다 — 한 줄에 문구 하나.
  - 키: 소문자·숫자·`_`를 `.`으로 이은 것. 앱 문구는 `<스크립트 이름>.<함수·상수>.<…>`, 서버 문구는 `server.<파일>.<…>`.
- **기획 표 이름**(영웅 이름·칭호·설명, 건물·연구·자원·병사·성장 이름)은 `data/*.csv`가 한국어 원본이다. 시드가 `data.<표>.<id>.<칸>` 키로
  texts 표에 함께 넣는다(예: `data.heroes.arteon.name`). 다른 언어 값은 texts.csv에 같은 키 행을 두고 그 언어 칸에 적는다.
- **앱**: `Lang.t("키")` (`const Lang := preload("res://scripts/lang.gd")`). 형식 문자열은 그대로 돌려주므로 `Lang.t("키") % [값]`.
  앱에 든 `data/texts.csv`로 시작하고, 접속하면 `GET /v1/texts?lang=ko`로 DB 값을 받아 덮어쓴 뒤 `user://texts_cache.json`에 둔다.
  상수였던 문구는 `static var`라 실행 중 처음 읽은 값을 쓴다 — DB에서 고친 문구는 늦어도 다음 실행부터 모든 화면에 보인다.
- **서버**: `txt('키', { 이름: 값 })` (`server/src/texts.ts`) — 값의 `{이름}`을 채운다. 시작할 때 저장소 texts.csv, 그 뒤 DB 값(기획 표와 같은 캐시 주기).
  상점·결제 상품·미션·길드 단어 목록처럼 모듈 상수인 문구는 서버가 켜질 때 한 번 읽는다(배포 때 새로 읽음).

## 새 문구 넣기

1. 코드에 평소처럼 한글 문자열을 쓴다(`"골드가 부족합니다"`, 서버는 `` `${name}님이 출석했습니다` ``).
2. 푸시 전에 `python3 dev/texts_extract.py <바꾼 .gd·.ts 파일들>` — 한글 문자열을 키 호출로 바꾸고 `data/texts.csv`에 행을 붙인다.
3. `python3 dev/texts_extract.py --check` — 옮기지 않은 한글이 남았으면 목록과 함께 실패한다. 쓰지 않는 키도 알려 준다.
4. main에 올린 뒤 `npm --prefix server run neon:seed` (DB에 새 키가 들어간다). 시드 전에도 앱·서버는 저장소 texts.csv 값으로 보인다.

옮기지 않는 것: 주석, `print`·`push_error`·`console.*`·`throw new Error` 같은 개발용 출력, 운영자 화면(`scripts/admin_panel.gd`),
약관·개인정보처리방침 문서(`server/src/legal.ts` — 법적 문서라 따로 관리), 욕설 필터 단어(`profanity.ts`), 기획 표 검증 오류(영어).

## 문구 고치기

- 문장만 바꿀 때는 **코드가 아니라 `data/texts.csv`의 `ko` 칸**을 고친다(한글로 grep하면 키가 나온다). 시드하면 앱을 새로 받지 않아도 바뀐다.
- 같은 문장이 여러 키에 있을 수 있다(쓰는 곳마다 따로 번역할 수 있게). 다 바꿀지는 쓰는 곳(note)을 보고 정한다.
- 코드가 문구를 비교하는 곳(예: `why == Lang.t("economy.levelup_block_2")`)은 만드는 쪽과 같은 키를 써야 한다.

## 다른 언어 켜기(나중)

`en`·`ja`·`zh` 칸을 채우고 시드한 뒤, 앱에서 `Lang.lang`을 그 언어로 두면(설정 화면에 언어 고르기를 붙일 때) 다음 실행부터 그 언어로 받는다.
서버가 만드는 문장(길드 기록·우편 제목 등)은 지금 한국어로 만들어 저장한다 — 언어별로 보이려면 그때 키+값으로 저장하게 바꾼다.
