# CastleRPG 아트 방향 (색 기준표)

한 줄 요약: **"햇살 좋은 장난감 왕국" — 각진 로우폴리 세계 위에 카툰 캐릭터.**
작은 화면(휴대폰 세로, 기본 줌)에서도 한눈에 읽히고, 스크린샷 한 장이 따뜻하고 아기자기해 보이는 것이 목표다.

## 1. 스타일 기둥

| 대상 | 방식 | 규칙 |
|---|---|---|
| 세계(바닥·성·건물·나무·바위·산) | 로우폴리(각진 면, 정점 색) | 면마다 음영(lowpoly 셰이더). 질감·사진 텍스처 없음. 큰 면 + 작은 디테일 조각 |
| 영웅·몬스터 | 카툰(Art.unit_style = "toon") | 두 단계 음영 + 테두리 빛, 외곽선 없음(Art.toon_outlines — 켜면 몸 색을 어둡게 한 1.4 px 선). 실사풍(real)은 쓰지 않는다 |
| 스킬·이펙트 | 로우폴리 조각 + 가산/반투명 빛 | 등급(R·SR·SSR)이 오를수록 크고 겹이 많다(fx.gd TIER) |
| UI | 둥근 패널(테두리 = 박스 색을 어둡게 한 얇은 선)·진한 외곽선 글자(UiKit) | 세계와 같은 따뜻한 색감 |

섞지 않는다: 사실적 질감, 사진 텍스처, 블러가 강한 후처리, 채도 낮은 회색 톤.

## 2. 팔레트(여름 기준 — 계절은 seasons.gd가 이 관계를 지키며 바꾼다)

| 역할 | 색 | 메모 |
|---|---|---|
| 풀(밝음/어두움) | `#7DA65A` / `#6F9650` | 바닥 격자 두 톤. 성 안 돌바닥과 대비 |
| 흙길·성 안 바닥 | `#C9B48A` / `#B59E74` | 따뜻한 베이지 |
| 물 | `#4FA3D9` (가장자리 `#8FD0F0`) | 채도 있는 하늘색, 물가 흰 띠 |
| 성벽 돌 | `#E8DCC4` / 그늘 `#BFB39C` | 크림 — 따뜻하게 |
| 지붕(아군 상징) | `#3F7FD9` | 파랑 = 우리 편 |
| 적 상징 | `#C8463C` | 빨강 계열 = 적 |
| 금(보상·SSR) | `#F2B233` | GRADE_COLORS.SSR과 같다 |
| 하늘(위 → 지평선) | `#7FB8EA` → `#DCEFFA` | 그라데이션 |
| 그림자 색 | `#4A5A8C` 계열(푸른 보라) | 그림자는 검정이 아니라 차가운 색 |

원칙: **빛은 따뜻하게(노랑·주황), 그늘은 차갑게(파랑·보라).** 같은 장면 안에서 채도는 주인공(영웅·이펙트) > 건물 > 바닥 순.

## 3. 조명

- 해(키 라이트): 따뜻한 흰빛 `#FFF1D6`, 세기 1.1~1.2, 카메라 시선을 가로질러 그림자가 화면 오른쪽 아래로.
- 환경광: 하늘에서 내려오는 차가운 빛 — 위쪽 면은 밝게, 그늘은 푸르게(검게 죽지 않게).
- 그림자: 부드러운 가장자리, 진하기 0.6 정도(완전 검정 금지).
- 후처리(Compatibility 렌더러에서 되는 범위): 약한 색 보정(채도 +5~10%, 대비 +5%), 가장자리 비네트 약하게, 밝은 이펙트만 살짝 번지는 블룸. 과하면 뺀다.

## 4. 크기·가독성

- 기본 줌(카메라 가로 46 m)에서 영웅 키 약 34 px(720 폭) — 네 성문 전투가 다 보이는 가장 가까운 줌. 더 키우려면 성문 하나씩 보는 구도가 필요.
- 큰 순간(SSR 스킬 발동)에는 카메라가 7% 잠깐 당겼다 돌아온다(2초에 한 번, 흔들림 설정을 따름).
- 영웅·몬스터 외곽선(켰을 때)은 줌과 무관하게 같은 픽셀 두께.
- 이름표·막대·말풍선은 캐릭터를 가리지 않는다.

## 5. 타격감(게임 필)

- 맞을 때: 피격 대상이 0.08초 하얗게 번쩍, 약간 뒤로 밀림(몬스터).
- 큰 한 방(치명타·SSR 스킬·보스 처치): 아주 짧은 멈춤(히트 스톱 30~60 ms) — 자주 쓰지 않는다.
- 처치: 작은 파편·빛 조각이 튀고 사라짐. 보스는 더 크게.
- 피해 숫자: 굵은 외곽선, 튀어 오르는 탄성 애니메이션, 종류별 색(일반 흰/노랑, 치명 주황 크게, 스킬 하늘, 독 초록, 회복 연두).

## 6. 하지 말 것

- 캐릭터마다 다른 셰이딩 방식 섞기.
- 채도 0 회색, 순검정 그림자, 순백 하이라이트가 넓게 깔리는 것.
- 화면 흔들림·멈춤을 잦게(피로감) — 설정(fx_shake)으로 끌 수 있어야 한다.
