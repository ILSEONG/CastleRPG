# CastleRPG 개정 14: 화면 회전 · 영웅 피규어 · FEVER · 수량 판매

작성일: 2026-10-01
기반: 개정 2~13. 충돌 시 이 문서가 우선한다. 사용자 지시에 따라 묻지 않고 진행한다.
계기: 사용자 요청(개정 12~13 작업 중 추가).
1. 식량 아이콘 교체(완료: 밥그릇, 1428046).
2. 화면을 꾹 누른 채 드래그하면 화면이 회전한다.
3. 영웅 메뉴의 육각형 대신 영웅 피규어를 보여 준다.
4. 방패 모양 "방치·무적" 표시를 뺀다(완료: 1428046).
5. [진행] 왼쪽에 FEVER 버튼(불꽃)을 둔다.
   - 방치 중 몬스터를 잡으면 빨간색이 조금씩 찬다. 200마리면 가득 찬다.
   - 가득 차면 이글이글 효과가 나고, 누르면 FEVER 3분이다.
   - FEVER 동안 몬스터가 3배로 나온다.
6. 상인 판매는 1단위로 수량을 넣어 판다(지금은 자원 전량만 판다).

## 1. 화면 회전 (꾹 누르고 드래그)

- 누른 채 `HOLD_SEC`(0.35초) 동안 `TAP_MAX_PX`보다 덜 움직이면 **회전 대기** 상태가 된다. 이 상태가 되면 누른 자리에 로우폴리 회전 표시(원 위에 화살 두 개, 0.3초 커짐)를 띄운다.
- 회전 대기에서 드래그하면 가로 이동량으로 카메라 요(yaw)를 돌린다(0.4°/논리 px). 각도 제한은 없다(360°).
  - 피치·줌·팬 중심은 그대로이고, 회전축은 지금 보고 있는 화면 중심의 지면 점이다.
- 회전 대기 후 **움직이지 않고 떼면** 지금의 길게 누르기 동작(건물 창, 0.5초)을 그대로 한다.
  - 판정: 누른 시간 ≥ 0.5초이고 이동 < TAP_MAX_PX면 길게 누르기다. 이동했으면 회전만 하고 아무 명령도 내리지 않는다.
- 0.35초 전에 움직이면 지금처럼 팬(드래그)이다. 두 손가락은 지금처럼 핀치 줌이다(회전 없음).
- 회전에 따라 같이 바뀌는 것:
  - HUD 성문 막대의 나침반 화살이 화면상 실제 방향을 가리킨다(매 프레임 카메라 요 반영).
  - 해 방향은 고정한다(세계 기준). 그림자는 세계에 붙어 있다.
  - 팬 한계, 줌 깊이 맞춤, 탭 판정(레이캐스트), 화면 공간 표시(HP 바·말풍선·숫자)는 카메라 기준이라 그대로 맞는다(테스트로 확인).
- 카메라가 다른 곳으로 갔다가 돌아오는 동작(창 포커스 등)이 있으면 요도 유지한다.

## 2. 영웅 피규어

- `scripts/portraits.gd`(오토로드 또는 main 아래 노드 하나): 숨긴 SubViewport 1개(정사각 256 px, 투명 배경)에서 영웅 모델(gear 포함, 대기 자세 첫 프레임, 살짝 왼쪽 위 3/4 시점, 로우폴리 재질과 같은 조명)을 한 번씩 렌더링한다. 결과는 `ImageTexture`로 id별 캐시에 둔다.
  - 렌더링은 한 프레임에 하나씩 큐로 처리한다. 요청 즉시 자리표시(등급 색 실루엣)를 돌려주고, 렌더가 끝나면 시그널 `ready(id)`로 교체한다.
  - 헤드리스(렌더러 없음)에서는 렌더를 건너뛰고 자리표시만 쓴다. 테스트는 API와 캐시 동작만 확인한다.
- 사용처: 육각 보석 자리를 피규어로 바꾼다.
  - 영웅 목록 카드
  - 배치 슬롯
  - 영웅 상세 큰 카드(살아 있는 미리보기: 상세에서는 같은 SubViewport를 실시간으로 써서 대기 애니메이션이 천천히 돈다. 손가락으로 좌우 드래그하면 모델이 돈다)
  - 모집 결과 카드
- 카드에서 등급 색은 테두리·배경 면으로 유지한다. 고유 색은 피규어 발밑 작은 받침 원판에 쓴다.
- 병사 UI(다음 작업 S2)도 같은 API(`portrait(model_spec_key)`)로 병종 피규어를 쓸 수 있게 일반화한다.
  - 키 예: `hero:ignis`, `soldier:cavalry`. 기병 말은 S1이 만드는 메시를 쓴다. S1이 아직 없으면 병사 키는 자리표시로 둔다.

## 3. FEVER

- 게이지(0~`fever_kills`=200):
  - **방치 모드**에서 몬스터를 처치할 때마다 +1(보스도 1)이다. 스테이지 모드의 처치는 세지 않는다.
  - FEVER 중에는 차지 않는다.
- 상태는 앱 로컬이다. `user://local.json`에 게이지·FEVER 남은 시간을 둔다(오프라인·온라인 공통).
  - 서버는 처치 골드 상한(토큰 버킷)으로 이미 보호된다. 그래서 서버 상태로 두지 않는다.
  - 테스트와 auto-stage는 파일을 쓰지 않는다.
- FEVER: 3분(`fever_sec`=180) 동안 방치 스폰 속도가 3배다(`fever_spawn_mult`=3). 방치 이벤트 간격을 1/3로 하거나 같은 시각에 3배 마리로 한다(웨이브 디렉터 기준). 살아 있는 몬스터 상한(120)은 그대로다.
  - 스테이지 모드에서는 FEVER 효과가 없다. 타이머는 계속 흐른다.
  - 끝나면 게이지는 0부터 다시 찬다.
- 설정 키는 `data/config.csv`(= DB `game_config`)의 `fever_kills`, `fever_sec`, `fever_spawn_mult`다. 앱이 읽는다.
- **FEVER 버튼**(상단 스테이지 패널, [진행] 바로 왼쪽, 정사각에 가까운 로우폴리 버튼):
  - 아이콘: 각진 불꽃(면 3~4개, 주황·빨강·노랑)
  - 게이지: 버튼 안쪽을 아래에서 위로 빨간 면 분할 채움(비율 = 게이지 / 200)과 작은 숫자 "73%"
  - 가득 참: 이글이글 효과를 준다.
    - 불꽃 꼭짓점이 일렁인다(사인 흔들림).
    - 테두리 주황 맥동을 준다.
    - 작은 불씨 삼각형 4~6개가 위로 떠오르며 사라진다.
    - 글자 "FEVER!"를 표시한다.
  - 누르면 FEVER가 시작된다.
    - 화면 가운데에 "FEVER!" 큰 글자(불꽃 색, 0.8초)
    - 버튼은 남은 시간 "2:59"와 계속 타는 불꽃
    - 화면 가장자리 붉은 빛(얇은 면 띠, 맥동)
  - 가득 차지 않았을 때 누르면 "몬스터 N마리 더" 알림이다.
- 처치 → 게이지 경로는 기존 처치 지점(spawner 사망 처리)에 한 줄로 단다.

## 4. 수량 판매

- 거래 창에서 자원 행의 [판매]를 누르면, 그 행 아래에 **수량 칸**이 펼쳐진다(다른 행은 접힌다).
  - [−] [입력칸(숫자만, 0~보유)] [+]: 누르고 있으면 가속(0.4초 후 초당 10 → 50)
  - 슬라이더(0~보유, 1 단위)
  - [최대]
  - "→ N골드"(그 자원 배율, floor)
  - [판매](수량 0이면 비활성)
- 입력칸: 모바일은 숫자 가상 키보드다. 보유보다 크면 보유로, 음수·문자는 0으로 바꾼다.
- [전부 판매]는 그대로 둔다(세 자원 전량).
- 서버 `POST /v1/sell {res, amount?}`:
  - amount는 1 이상 정수이고 보유 이하다. 생략하면 전량이다(`res = "all"`이면 amount는 쓰지 않는다).
  - 보유를 넘으면 409 `not_enough`, 형식 오류는 400이다.
  - 판매 골드 = floor(amount × 단가 × 그 자원 배율)이다.
- 오프라인 `Economy.sell(res, now, amount := -1)`
- 테스트:
  - 서버: 부분 판매, 보유 초과 409, 정수 아님 400, 전량 생략
  - 앱: 수량 판매 계산
  - 입력 체크: [판매] → 수량 칸, [+]·[−]·입력·[최대], 판매 후 보유 감소와 골드 증가

## 5. 테스트(공통)

- 로직: FEVER 게이지(방치 처치만, 200에서 가득, FEVER 중 안 참), FEVER 스폰 배율, 회전 판정(시간·이동 → 팬/회전/길게 누르기/탭), 피규어 캐시 API
- 입력 체크:
  - 꾹 누르고 드래그하면 요가 바뀌고 명령이 없다. 꾹 누르고 떼면 건물 창이다.
  - 회전 후 탭 판정(벌목장 탭 수집)이 여전히 맞다. 나침반 화살 방향이 갱신된다.
  - FEVER 버튼: 미충전 알림, 충전 후 누르면 FEVER 시작·남은 시간 표시
  - 수량 판매
- AI 체크: FEVER 중 방치 스폰 수가 같은 시간 대비 3배(±1 웨이브)이고, 스테이지 모드는 변화가 없다.
- 웹 캡처(컨트롤러): 회전한 화면, 영웅 목록·상세 피규어, 모집 결과 피규어, FEVER 버튼(게이지 중간·가득 이글이글·FEVER 중), 수량 칸
