# CastleRPG 개정 17: 승급 스킬 해금 · 화려한 스킬 연출

작성일: 2026-10-02
기반: 개정 2~16. 충돌 시 이 문서가 우선한다. 사용자 지시에 따라 묻지 않고 진행한다.
계기: 사용자 요청.
- 영웅 스킬을 지금보다 화려하게 한다.
- SR·SSR은 3성·5성에서 스킬이 하나씩 해금되고, R은 3성에서 하나 해금된다.

## 1. 해금 규칙

- "성"은 승급 단계(★, 개정 15)다.
- 스킬 1은 처음부터 쓴다. 스킬 2는 ★3에서 해금된다. 스킬 3은 ★5에서 해금되며 SR·SSR만 가진다.
  - 그래서 SSR·SR은 스킬 3개, R은 스킬 2개다.
- 설정 키: `skill2_unlock_star`(3), `skill3_unlock_star`(5)
- 잠긴 스킬은 전투에 쓰지 않는다. 능력치에도 영향이 없다.

## 3. 화려한 스킬 연출 (로우폴리, 모바일 성능 고려)

- **스킬 발동 표시**:
  - 쿨 스킬(aoe_blast·heal_aura·gate_repair)이나 확률 스킬(crit·stun·execute)이 터지면, 영웅 머리 위에 스킬 이름 띠("화염구!")를 고유 색으로 0.8초 띄운다.
  - 같은 영웅의 띠는 최소 1.5초 간격으로 띄운다.
  - 동시에 영웅 발밑 링이 한 번 밝게 맥동한다.
- **aoe_blast**: 고유 색 20면체가 커지면서 다음이 함께 퍼진다.
  - 바닥 충격파 고리(납작한 6각 고리)
  - 각진 파편 8~12개(사방으로 튀었다가 떨어짐)
  - 0.15초 섬광(가산 색)
  - SSR이면 카메라를 약하게 흔든다(0.15초, 진폭 0.25 m, 연속이면 합치지 않음).
- **chain**: 번개 선을 두께 2배, 지그재그 4~6꺾임으로 그린다. 맞는 지점마다 작은 별 모양 불꽃이 튄다. 하늘색이나 고유 색 이중선(굵은 반투명 + 가는 밝은 선)이다.
- **heal_aura**: 초록 고리가 퍼지고, 회복받는 영웅마다 각진 십자 2~3개가 떠오른다.
- **atk_aura**(지속): 받는 영웅 발밑에 은은한 주황 링을 둔다. 버프 표시다.
- **stun**: 대상 머리 위 별 3개가 빙글 돈다(지금보다 크게). 기절 시간 동안 유지한다.
- **slow / poison**: 대상 발밑에 하늘색 결정 / 초록 거품이 기절처럼 지속 동안 남는다.
- **crit**: 맞은 지점에 큰 각진 불꽃(별 8각, 0.2초)을 띄운다. 피해 숫자는 이미 크다.
- **execute / boss_slayer**: 맞은 지점에 붉은 X 베기 자국(각진 두 줄, 0.3초)을 띄운다.
- **gate_repair**: 성문에 금색 망치 반짝임과 위로 오르는 금빛 조각 4개를 띄운다.
- **multishot**: 투사체에 고유 색 꼬리를 단다(짧은 리본 3마디).
- **성능**:
  - 이펙트 노드는 풀링하거나 수명 뒤 해제한다. 동시 상한은 지금 fx 상한(예: 60)을 지킨다.
  - 재질은 공유하고 그림자는 없다.
  - 파편과 링은 MeshKit 저면체를 쓴다.
  - 카메라 흔들림은 설정 `fx_shake`(기본 켬)로 끌 수 있다(테스트에서는 끔).

## 4. UI

- 영웅 상세의 스킬 목록은 3줄(R은 2줄)이다.
  - 잠긴 스킬: 회색, 자물쇠 아이콘, "★3에서 해금" / "★5에서 해금"
  - 해금된 스킬: 지금처럼 수치가 들어간 설명
- 승급 미리보기에 "★3 달성 시 스킬 해금: 화상"처럼 해금될 스킬을 알린다.
- 승급 성공으로 스킬이 해금되면 알림 "스킬 해금! 화상"과 스킬 줄 반짝임을 보여 준다.
