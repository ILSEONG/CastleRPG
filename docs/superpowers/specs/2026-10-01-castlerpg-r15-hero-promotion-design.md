# CastleRPG 개정 15: 영웅 승급 (중복 영웅 모으기)

작성일: 2026-10-01
기반: 개정 2~14. 충돌 시 이 문서가 우선한다. 사용자 지시에 따라 묻지 않고 진행한다.
계기: 사용자 요청.
- 같은 영웅을 여러 개 모으면 승급할 수 있다.
- 승급에는 5, 25, 50, 100, 200개가 필요하다.
- 승급하면 스펙이 1.5배 강해진다(기본 스펙도, 레벨업 스펙도 1.5배).

## 1. 규칙 (개정 10의 "별(중복 자동 +10%)"을 대체)

- 영웅마다 **조각(shards)** 과 **승급 단계(promotion, 0~5)** 를 둔다.
  - 처음 얻으면 조각 0, 승급 0이다.
  - 모집에서 이미 가진 영웅이 다시 나오면 조각 +1이다.
- 승급 p → p+1에 드는 조각(소모): `promote_shards` = `5|25|50|100|200`(p = 0..4). 최대 승급은 5다.
- 능력치: 최종 HP·공격 = 표 기본 × 레벨 배율 × `promote_mult`(1.5)^p × 건물 보너스(연구소 등)
  - 기본과 레벨업분이 모두 1.5배가 된다(곱 하나). 승급 5면 약 7.59배다.
- 최대 레벨: `hero_max_level_base`(20) + `hero_max_level_per_promotion`(10) × p. 승급 5면 70이다.
- 기존 설정 `hero_star_bonus`, `hero_max_stars`, `hero_max_level_per_star`는 지우고 위 키로 바꾼다.
- 화면의 ★는 이제 승급 단계다(금색 별 p개).
- 전투력도 위 능력치로 계산한다.

## 2. 서버

- 마이그레이션(번호는 그때 최신 다음):
  - `player_heroes`에 `shards integer not null default 0 check (shards >= 0)`, `promotion integer not null default 0 check (promotion between 0 and 5)`를 더한다.
  - 기존 행: shards = copies − 1, promotion = 0
- 모집: 중복이면 copies +1, shards +1이다. 결과 항목에 `shards`를 넣는다.
- `POST /v1/hero/promote {hero_id}`:
  - 보유하지 않았으면 404, 최대 승급이면 409 `max_promotion`, 조각이 부족하면 409 `not_enough_shards`다.
  - 성공하면 원자적(version 가드)으로 shards −= 필요, promotion += 1, economy_log `promote`를 남긴다.
  - 응답: 플레이어 응답 + `promotion`
- 레벨업 상한 검사는 승급 기준이다.
- 플레이어 응답 `player.heroes`는 `{id: {copies, level, shards, promotion}}`이다.
- 테스트:
  - 승급 비용 표, 부족·최대 409, 원자성(동시 2건)
  - 모집 중복 → 조각
  - 상한 레벨 승급 반영
  - 마이그레이션 백필

## 3. 앱

- 상태: 영웅별 shards·promotion이다.
  - 오프라인 save 다음 버전: 이전 별 정보는 shards = copies − 1, promotion 0으로 옮긴다.
  - 온라인 응답을 쓴다.
  - 승급 요청은 **재전송 금지**다. 실패하면 알림을 띄우고 상태를 새로 받는다.
- 능력치·전투력·최대 레벨 함수는 승급 기준이다. 반영 시점은 레벨업과 같다(리필 / 방치면 그 영웅만 즉시).
- **영웅 목록 카드**: 피규어, 이름, Lv, 금색 ★×p, 아래 조각 막대 "조각 3 / 5"(최대 승급이면 "MAX"). 승급 가능하면 ▲ 배지(레벨업 가능 ▲와 구분되게 금색 ⬆).
- **영웅 상세**:
  - [레벨업] 옆에 **[승급]** 버튼을 둔다.
    - 버튼 안: "조각 12 / 25"
    - 불가 이유: "조각 부족", "최대 승급"
  - 승급 미리보기: HP·공격 "→ ×1.5", 최대 레벨 "40 → 50"
  - 성공 연출:
    - 피규어 주위로 금색 로우폴리 빛 조각이 퍼진다.
    - 별 하나가 날아와 박힌다.
    - 능력치 숫자가 초록으로 반짝인다.
- **모집 결과 카드**: 새 영웅이면 "NEW", 중복이면 "+1 조각"과 그 영웅의 조각 막대를 보여 준다.
- 테스트:
  - 로직: 승급 공식·비용·상한, save 이전
  - 입력 체크: 상세 [승급]으로 조각이 줄고 ★와 능력치가 오른다
  - 통합: 서버 승급·재접속 복원
