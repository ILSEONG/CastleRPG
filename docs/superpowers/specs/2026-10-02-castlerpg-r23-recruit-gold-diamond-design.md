# CastleRPG 개정 23: 모집 세분화(골드 · 다이아) · 모집 레벨 · 모집 창 일러스트

작성일: 2026-10-02
기반: 개정 10(모집)·15(승급). 충돌 시 이 문서가 우선한다. 사용자 지시에 따라 묻지 않고 진행한다.

계기(사용자):
- 주점 모집을 골드와 다이아 두 가지로 나눈다.
- 골드 모집은 1회 3,000골드다. 모집 레벨이 있어서 일정 횟수를 채우면 레벨이 오르고, 비용과 좋은 영웅 확률이 함께 오른다.
- 다이아는 현금으로 사는 특수 재화다. 모집 레벨이 없고, 확률은 골드보다 좋아야 한다.
- 모집 창 상단 가운데에 우리 영웅 중 가장 멋진 영웅이 스킬을 쓰는 일러스트를 넣는다.

## 1. 골드 모집 (레벨)

- 골드 모집 레벨 L은 1~10이다.
- 1회 비용 = round_to_100(3000 × 1.15^(L−1)). 단계별 값: L1 3,000 · L2 3,450 · L5 5,250 · L10 10,550
- 10회 비용 = 1회 × 10이다. 할인도 SR 이상 보장도 없다(사용자 요청 2026-10-03: 골드 10회 혜택 삭제). SR 이상 1장 보장은 다이아 10회에만 있다.
- 확률: SSR = 0.5% + 0.1%p × (L−1)(L10 1.4%), SR = 5% + 0.5%p × (L−1)(L10 9.5%), R = 나머지. 주점 건물 보너스(개정 12)는 여기에 더한다.
  (사용자 요청 2026-10-03으로 낮춤 — 처음 값은 SSR 3% + 0.4%p, SR 17% + 1%p였다.)
- 레벨업 조건: 그 레벨에서 누적 모집 횟수(10회는 10번으로 센다)가 `30 × L` 이상이면 L+1. L1→2는 30회, L9→10은 270회다. 남은 횟수는 다음 레벨로 넘긴다.
- 표시: "골드 모집 Lv 3 · 다음 레벨까지 42/90", 진행 막대, 다음 레벨 확률·비용 미리보기
- 레벨업하면 알림 "골드 모집 Lv 4! SSR 4.2%"를 띄운다.
- 설정 키:
  - `gacha_gold_cost_base`(3000), `gacha_gold_cost_growth`(1.15)
  - `gacha_gold_level_max`(10), `gacha_gold_level_pulls`(30)
  - `gacha_gold_ssr_base`(0.005), `gacha_gold_ssr_step`(0.001), `gacha_gold_sr_base`(0.05), `gacha_gold_sr_step`(0.005)
  - 기존 `gacha_cost_1`·`gacha_cost_10`·`gacha_rate_*`는 지운다.

## 2. 다이아 (특수 재화)

- 새 재화 **다이아**를 둔다. 서버 권위로 `player_state.diamonds bigint ≥ 0`에 저장한다.
- 획득: 현금 구매. **실결제(Google Play / App Store 결제 연동)는 이번 범위 밖**이다.
  - 상점 창에 상품 목록(예: 💎 300 · 1,200원 / 💎 1,000 · 3,900원 / 💎 3,000 · 11,000원 / 💎 6,500 · 22,000원)을 보여 주되 [구매] 버튼은 "준비 중"이다.
  - 개발용: 테스트 훅 `POST /v1/test/grant_diamonds`(ALLOW_TEST_HOOKS만), 앱 `?econ-demo`는 다이아 3,000으로 시작한다.
- 다이아 모집에는 레벨이 없다.
  - 1회 300, 10회 2,700(SR 이상 1장 보장)
  - 확률: SSR 8%, SR 30%, R 62%. 골드 최대 레벨(1.4% / 9.5%)보다 항상 좋다. 주점 보너스는 다이아에도 더한다.
  - 천장: 다이아 모집 누적 50회 동안 SSR이 없으면 50번째를 SSR로 확정한다. 카운터는 SSR이 나오면 0이 된다. 다이아에만 적용하고, 표시는 "SSR 확정까지 37회"다.
- 설정 키: `gacha_dia_cost_1`, `gacha_dia_cost_10`, `gacha_dia_ssr`, `gacha_dia_sr`, `gacha_dia_pity`(50)
- 상단 바: 재화 칩을 5개로 늘린다(골드, 목재, 석재, 식량, 다이아). 폭을 줄여 720에 맞춘다. 다이아 아이콘은 각진 하늘색 보석이다.

## 3. 서버

- 마이그레이션 015:
  - `player_state.diamonds bigint not null default 0 check (diamonds ≥ 0)`
  - `player_state.gacha_gold_level int default 1`, `gacha_gold_pulls int default 0`(현재 레벨 안 누적), `gacha_dia_pity int default 0`
- `POST /v1/gacha {count: 1|10, currency: "gold"|"diamond"}`
  - currency를 생략하면 gold다(하위 호환).
  - 골드는 레벨 비용·확률을 쓰고, 모집 수만큼 누적한 뒤 레벨업을 처리한다(한 번에 여러 레벨 가능, 최대 10).
  - 다이아는 비용을 차감하고, 천장을 처리한다.
  - 원자적(버전 가드)이다. 409 `not_enough_gold` / `not_enough_diamonds`. 로그에 currency·level·pity를 남긴다.
- 플레이어 응답에 다음을 더한다: `diamonds`, `gacha: {gold_level, gold_pulls, gold_next, dia_pity}`
- 테스트:
  - 레벨별 비용·확률(표본), 레벨업 누적·넘김·최대
  - 다이아 확률(표본, 골드보다 좋음), 천장 50(결정적 RNG 주입)
  - 부족 시 409, 원자성, 마이그레이션, 하위 호환

## 4. 앱

- Economy: `diamonds`, `gacha_state()`, `gacha_cost(currency, count)`, `gacha_rates(currency)`, `gacha(count, currency)`(온라인 재전송 금지, 오프라인 같은 규칙, save 다음 버전), 시그널.
- **모집 창**:
  - 상단 가운데: **키 아트 일러스트**(§5)
  - 그 아래 탭 두 개: **[골드 모집] [다이아 모집]**
  - 골드 탭: 레벨 배지, 진행 막대, 확률 한 줄(SSR·SR·R %), [1회 3,000] [10회 30,000]
  - 다이아 탭: 💎 보유, 확률 한 줄, 천장 "SSR 확정까지 n회", [1회 💎300] [10회 💎2,700 · SR 이상 1장], [다이아 상점] 버튼
  - 결과 화면·[재모집]·자동 모집(개정 17)은 선택한 재화로 동작한다. 자동 모집은 골드에서만 쓴다(내 결정: 현금 재화 자동 소모 방지). 다이아 탭에서는 자동 체크를 숨긴다.
- **다이아 상점 창**: 상품 4개 카드(보석 더미 아이콘 크기별), 가격, [구매] 비활성 "준비 중", 안내 "결제 기능은 출시 전에 연결됩니다".

## 5. 모집 창 키 아트

- "우리 영웅 중 가장 멋진 영웅": **이그니스(SSR 화염 대마법사)가 화염구를 쏘는 순간**으로 정한다(가장 화려한 스킬, 내 결정).
- 렌더 방식: `scripts/scene_snap.gd`(던전 배너 작업이 만드는 범용 렌더러 `snap(key, size, build)`)로 한 번 렌더해서 캐시한다.
  - 장면: 어두운 배경 그라데이션 + 바닥 원형 단상
  - 이그니스: 고유 외형(영웅 외형 작업 반영), 공격 자세 프레임
  - 앞쪽에 커다란 화염 20면체와 불꽃 파편, 빛기둥, 불씨 입자
  - 역광 림라이트, 살짝 낮은 각도의 영웅적 구도
  - 크기는 창 폭 × 약 300 논리 px이고, 2배로 렌더한다.
- 창에서는 느린 줌 인/아웃(Ken Burns)과 가장자리 비네트를 준다. 위에 "주점 · 영웅 모집" 제목을 겹친다(외곽선).
- 헤드리스(렌더 불가)에서는 자리표시 그라데이션을 쓴다.
- scene_snap이 아직 병합되지 않았으면 같은 API를 쓰도록 짜 두고, main을 병합한 뒤 연결한다.

## 6. 테스트(앱)

- 로직: 비용·확률·레벨 공식, 천장, save 이전
- 입력 체크:
  - 골드·다이아 탭 전환
  - 골드 1회로 골드가 줄고 누적이 오른다
  - 30회를 채우면 레벨업(비용·확률 표시 갱신)
  - 다이아 1회로 다이아가 줄고, 천장 카운트가 줄어든다
  - 다이아 부족 비활성
  - 다이아 상점 [구매] 비활성
  - 상단 다이아 칩
- 통합: 서버 골드 레벨업, 다이아 모집·천장, 재접속 복원
- 웹 캡처(컨트롤러): 모집 창 키 아트, 두 탭, 상점
