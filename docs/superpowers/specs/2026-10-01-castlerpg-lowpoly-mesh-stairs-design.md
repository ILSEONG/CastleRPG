# CastleRPG 개정 6: 로우폴리 메시 · 성벽 계단 · 성 1.25배

작성일: 2026-10-01
기반: 개정 2~5. 충돌 시 이 문서가 우선한다.
계기: 사용자 요청 — ① 전체적으로, 특히 성 안 건물들을 더 로우폴리한 메시로 ② 각 면 성문 좌우에 성벽 위로 오르는 계단, 성벽 위는 계단으로만 오른다 ③ 성을 지금의 1.2배로.

## 1. 로우폴리 메시 (코드로 만든 메시)

KayKit 건물·성벽·자연물은 부품이 많고 세밀하다. 음영만 각지게 한 지금 상태로는 로우폴리 느낌이 약하다. 그래서 이것들을 코드로 만든 메시로 바꾼다. 면이 적고, 면마다 단색(정점 색, 텍스처 없음)이며, 각진 음영이다.

- **도구**: `scripts/mesh_kit.gd`. 삼각형마다 정점을 따로 두는 SurfaceTool 래퍼다.
  - 도형: 박스, 박공지붕, 피라미드, 원기둥(면 수 지정), 원뿔, 울퉁불퉁한 바위(각진 다면체 흔들기).
  - 부품마다 변환(위치·회전·배율)을 걸 수 있다.
  - 한 물체(건물 하나, 성벽 한 면 등)는 메시 하나로 합쳐 그리기 호출 하나로 그린다.
- **재질**: 기존 로우폴리 셰이더에 `use_vertex_color`를 더해 정점 색을 쓴다. 재질은 하나를 공유한다.
- **대상**:
  - 성: 성벽(위 톱니 포함), 성문 문루(성문 위 통로 포함, 나무 문짝 두 짝), 모서리 탑(8각 기둥 + 원뿔 지붕), 계단(§2).
  - 건물 8종 (§4 레시피)
  - 성 밖 자연물: 침엽수(층층이 원뿔), 활엽수(각진 둥근 수관 + 줄기), 바위, 덤불. 변형 몇 가지를 만들어 MultiMesh로 그린다.
  - 가장자리 산: 각진 원뿔 산. 초록 기슭, 회색 바위, 흰 눈 꼭대기의 세 띠. 변형 몇 가지를 MultiMesh로.
- **유지**: 캐릭터·무기·화살은 KayKit 그대로 둔다(애니메이션). 각진 음영은 그대로 적용된다.
- **삭제**: 더 이상 쓰지 않는 KayKit 헥스 에셋(건물·성벽·탑·자연물·산)과 그 받기 줄은 지운다.

## 2. 성벽 계단

- 각 면 성문 좌우(end = −1/+1)에 하나씩, 모두 8개. 성벽 안쪽 면에 붙은 폭 2m(1타일) 띠에 놓인다. 성문 쪽이 위다.
  - 윗단: 성문 가장자리에서 0.5m, 높이 `WALL_H`
  - 아랫단: 윗단에서 성문 반대 방향으로 6m, 지면. 8단.
- `Balance`: `STAIR_W = 2.0`, `STAIR_GAP = 0.5`, `STAIR_RUN = 6.0`, `STAIR_STEPS = 8`.
- 위치 (`Formation`, 순수):
  - `stair_bottom(half, side, end)`: 면 방향 × (half − STAIR_W/2) + 옆 방향 × end × (GATE_W/2 + STAIR_GAP + STAIR_RUN), y=0
  - `stair_top`: 같은 줄, 옆 방향 × end × (GATE_W/2 + STAIR_GAP), y=WALL_H
  - `wall_landing`: 성벽 중심선(half + WALL_T/2), 옆 방향은 윗단과 같고 y=WALL_H
  - `stair_approach(half, side, end)`: 계단 띠 밖 지상 지점. 면 방향 × (half − STAIR_W − GATE_PASS_MARGIN) + 옆 방향 × end × (GATE_W/2 + STAIR_GAP + STAIR_RUN + GATE_PASS_MARGIN), y=0. 아랫단 너머 1m, 띠 안쪽 가장자리에서 1m.
  - `gate_inner(half, side)`(성문 안쪽 통과 지점)도 계단 띠 밖이다: 면 방향 × (half − STAIR_W − GATE_PASS_MARGIN) = half − 3m(현재 값). 성 안팎 경로와 부서진 성문으로 들어오는 괴물의 겨냥점은 전과 같이 이것을 쓴다.
- **영역**: `region(half, p)`. y > WALL_H/2이면 성벽 위(계단 윗부분 포함), 아니면 바깥면 안쪽이 성 안, 그 밖은 성 밖이다. `is_inside()`는 그대로다(성벽 위도 안).
- **경로** (`route`): 성벽 위는 계단으로만 오르내린다. 지상 구간은 계단 띠 밖(stair_approach·gate_inner)에서 끊기므로 계단 발판(띠 × 계단 길이)을 지나지 않고, 띠에는 아랫단 너머로만 들어간다.
  - 성벽 위 → 같은 면 성벽 위: 성벽 위를 곧장 걷는다(성문 위 통로 포함).
  - 성벽 위 → 그 밖: 그 면에서 현재 위치 쪽(end) 계단으로 내려간다(landing → top → bottom → approach). 이어서 approach에서 지상 경로(기존 성 안/밖/성문 규칙)를 따른다.
  - 그 밖 → 성벽 위: 지상 경로로 목표 면·쪽의 계단 앞(approach)까지 간다. 그다음 bottom → top → landing → 목표 순이다.
  - 다른 면 성벽 위끼리: 내려가서 성 안을 지나 올라간다.
- 계단 띠는 건물 배치에서 비운다(벽 쪽 1타일 여유 줄 안).

## 3. 성 크기 1.25배

- 1.2배 요청이지만 2m 격자·타일 좌표에 맞추려고 1.25배로 한다. `INTERIOR_TILES` [16, 20, 24] → [20, 24, 28]. 레벨 1 내부는 32m에서 40m가 된다.
- 성벽 두께·높이, 성문 폭, 유닛 크기는 그대로다.
- 건물 재배치(레벨 1 내부 타일 −10..9, 여유 반영 −9..8, 십자 도로 −1·0):

| id | cell | size |
|---|---|---|
| keep | (−2, −2) | 4×4 |
| barracks | (2, −8) | 3×3 |
| tavern | (6, −5) | 3×3 |
| lab | (−5, −8) | 3×3 |
| houses | (−9, −5) | 3×3 |
| lumber | (2, 5) | 3×3 |
| quarry | (6, 2) | 3×3 |
| farm | (−5, 5) | 3×3 |

- 기본 줌 `CAMERA_SIZE_DEFAULT` 56 → 66 (성 전체가 들어오게). 바닥·스폰·자연물·테두리는 `half`·`MAP_HALF`에서 계산되므로 따라온다.

## 4. 건물 레시피 (밝고 채도 낮은 팔레트, 부지 = 3×3타일 6m, 성채 4×4 8m)

| 건물 | 구성 |
|---|---|
| 성채 | 넓은 석조 본체(각진 박스), 네 모서리 6각 탑(파란 원뿔 지붕), 가운데 높은 8각 탑(파란 원뿔 + 깃발), 문 |
| 막사 | 긴 목조 막사(박스 + 빨간 박공지붕), 문, 무기 걸이, 깃대 |
| 주점 | 2층 집(흰 벽 + 주황 박공지붕), 굴뚝, 통 2개(6각 기둥), 간판 |
| 연구소 | 8각 원통 탑(보라 원뿔 지붕), 작은 부속 건물, 둥근 창 |
| 민가 | 작은 집 2~3채(색 다른 박공지붕), 울타리 |
| 벌목장 | 기둥 + 지붕의 작업 헛간, 누운 통나무 더미(5각 기둥), 그루터기 |
| 채석장 | 각진 바위 더미, 잘린 석재 블록, 작은 기중기(박스) |
| 농장 | 헛간(빨간 박공지붕), 밭고랑(노랑·초록 납작 박스 줄), 작은 풍차(탑 + 날개 박스) |

부지를 넘지 않는다. 지붕 꼭대기 위 1m에 이름표를 둔다(기존).

## 5. 구조

- 신규 `scripts/mesh_kit.gd`: 도형 도구, 정점 색 재질.
- 신규 `scripts/town_kit.gd`: 건물 8종·성벽 부품·자연물·산 레시피(메시 생성 함수).
- `castle.gd`, `buildings.gd`: 레시피 사용.
- `art.gd`: 헥스 경로 표 정리.
- `formation.gd`: 계단·영역·경로.
- `balance.gd`: 계단 상수, 내부 크기, 건물 배치, 카메라.
- `lowpoly.gdshaderinc`: `use_vertex_color`.
- 스크립트 상한 16 → 18.

## 6. 테스트와 확인 (창 금지)

- **로직**:
  - 새 배치가 기존 규칙 테스트(겹침·도로·여유)를 통과한다.
  - 계단 위치: 윗단 y=WALL_H, 아랫단 y=0, 둘 다 성 안 띠이며 성문 폭 밖이다.
  - 경로: 성 안 → 성벽 위는 계단 경유, 성벽 위 → 성 밖은 계단 뒤 성문, 다른 면 성벽 위끼리는 내려갔다 올라가고, 같은 면 성벽 위끼리는 곧장 간다.
  - 경로의 어느 구간도 계단·성문 밖에서 성벽 띠를 가로지르지 않는다.
  - 지상 구간(양 끝 y=0)은 어느 계단 발판도 지나지 않는다(샘플 검사, 모든 면·end의 성 안 ↔ 성벽 위 포함).
  - mesh_kit 도형의 삼각형·정점 수, 법선 방향, 정점 색.
  - 레시피 메시가 부지·높이 한계 안에 있다(AABB).
- **입력 체크·AI 체크**: 내부 크기 변경에 맞춰 좌표를 고친 뒤 전부 통과한다. 성벽 탭으로 오르는 영웅이 계단 아랫단을 지나는 사례를 추가한다.
- **엔드투엔드**: 스테이지 1→2, 패배 → 방치 복귀.
- **웹 캡처**:
  - 전경: 커진 성, 로우폴리 성벽·탑·문루·계단, 건물 8종
  - 근접: 건물 레시피, 계단
  - 궁수를 다른 면 성벽으로 보내는 동안 계단을 오르는 모습
  - 줌아웃: 로우폴리 나무·산
