# CastleRPG 개정 11: 자원별 시세 · 영웅 레벨업과 하단 탭 · 피해량 숫자

작성일: 2026-10-01
기반: 개정 2~10. 충돌 시 이 문서가 우선한다. 사용자 지시에 따라 묻지 않고 진행하며, 결정은 이 문서에 적는다.
계기: 사용자 요청.
1. 상인의 교환 배율은 자원마다 다르다. 배율이 바뀌기까지 남은 시간을 분·초로 보여 준다.
2. 영웅은 레벨업할 수 있다. 하단에 탭처럼 버튼을 두고, 누르면 보유 영웅이 나온다. 비슷한 게임의 영웅 레벨업 UI를 참고한다.
3. 유닛이 공격할 때 HP 바 위에 피해량을 표시한다.

## 1. 자원별 시세

- 매 정시 자원마다 따로 뽑는다. 분포는 개정 7 §3과 같다(0.5~1.5, 0.1 단위, P(0.5) : P(1.5) = 3 : 1, 5% ×2.0).
- 결정적이다.
  - 서버: 시드 = (시간 칸, 자원 순번)을 섞은 값
  - 앱 오프라인: 같은 방식으로 자원 id를 섞은 값
  - 온라인에서는 서버 값만 쓴다.
- API: `merchant: {rates: {wood, stone, food}, next_change}`. 기존 `merchant.rate`는 없애고, `/v1/sell` 응답의 `rate`는 `rates`로 바꾼다.
- 판매 골드 = floor(수량 × 단가 × 그 자원 배율)이다. 전부 판매는 자원마다 자기 배율로 계산한다.
- 거래 창:
  - 행마다 자기 배율을 색으로 보여 준다(1 미만 빨강, 1 기본, 1 초과 초록, 2 금색 + 반짝임).
  - 위에 "다음 시세까지 mm:ss"를 매초 갱신한다.
- 상인 이름표: "상인 · mm:ss"(다음 변경까지)로 매초 갱신한다. 아래 작은 줄에 배율이 가장 높은 자원 아이콘과 배율 "목재 ×1.4"를 둔다(같으면 목재 → 석재 → 식량 순).

## 2. 영웅 레벨업

### 2.1 규칙(기획 데이터 = DB `game_config`, `data/config.csv`)

| 키 | 값 | 뜻 |
|---|---|---|
| hero_max_level_base | 20 | 별 0일 때 최대 레벨 |
| hero_max_level_per_star | 10 | 별 하나당 최대 레벨 + (별 5 → 70) |
| hero_level_stat | 0.06 | 레벨당 HP·공격 +6%(1레벨 기준 직선) |
| levelup_gold_R / _SR / _SSR | 30 / 60 / 120 | L → L+1 골드 = round(값 × 1.12^(L−1)) |
| levelup_food_R / _SR / _SSR | 10 / 20 / 40 | L → L+1 식량 = 값 × L |

- 최종 HP·공격 = 표 기본값 × (1 + 0.06 × (L − 1)) × (1 + 0.1 × 별)
- 전투력(목록 정렬·표시용) = round(HP / 10 + 공격 × 2 / 공격 간격)
- 비용은 정수 골드(tenths × 10 차감) + 식량이다. 둘 다 있어야 한다.
- 레벨은 최대 레벨을 넘을 수 없다. 별이 오르면 상한이 함께 오른다.
- 반영 시점은 배치 변경과 같다: 다음 리필 때, 방치 모드면 즉시 그 영웅만 다시 만든다.

### 2.2 서버

- 마이그레이션 006: `player_heroes.level integer not null default 1 check (level >= 1)`
- 플레이어 응답 `player.heroes`는 `{hero_id: {copies, level}}`로 바꾼다. 앱의 기존 `{hero_id: copies}` 처리도 맞춘다.
- `POST /v1/hero/levelup {hero_id, count}`:
  - count는 1..100 정수다.
  - 보유하지 않은 영웅이면 404다.
  - 상한을 넘거나 골드·식량이 모자라면 409(`max_level` / `not_enough`)다.
  - 성공하면 플레이어 응답 + `level`이다.
  - 원자적이어야 한다: version 가드, 비용 합계 한 번에 차감. economy_log에 `levelup`을 남긴다.
- 오프라인은 save v3(heroes에 level 포함, v2 → v3 이전은 level 1)에 저장한다.

### 2.3 하단 탭 바 (방치형 RPG 공통 UX 참고: 하단 고정 내비게이션)

- 화면 맨 아래에 로우폴리 탭 바 1줄(높이 약 104 논리 px)을 두고, 탭 4개를 같은 폭으로 놓는다. 탭마다 각진 아이콘과 글자가 있다.
  - **성**: 모든 창을 닫고 전장으로 돌아간다(기본 선택).
  - **영웅**: 영웅 목록
  - **모집**: 모집 창(주점 탭과 같다)
  - **상인**: 거래 창(상인 탭과 같다)
- 선택된 탭은 호박색 면과 위로 4px 올라온 모양이고, 나머지는 강철색이다.
- [스테이지 진행] 큰 버튼은 탭 바 바로 위로 올린다. 기존 6각 [영웅] 버튼은 없앤다.
- 탭이 연 창이 닫히면 탭은 **성**으로 돌아간다. 건물 탭으로 연 창도 해당 탭을 선택 상태로 표시한다.
- 끊김 띠·알림은 탭 바와 큰 버튼을 가리지 않는다.

### 2.4 영웅 목록 (영웅 탭)

- 상단 바와 탭 바 사이를 채우는 시트다. 뒤 입력은 막히고, 탭 바는 계속 쓸 수 있다.
- 위: 배치 슬롯 4칸(개정 10 영웅 창 기능 그대로 — 슬롯 탭 → 카드 탭으로 배치, [적용]).
- 정렬 버튼: 전투력 / 등급 / 레벨(누를 때마다 바뀐다)
- 보유 영웅 격자(3열, 스크롤). 카드 내용:
  - 등급 테두리, 고유 색 보석, 이름
  - "Lv 12"
  - 별
  - 전투력
  - 배치 중이면 "배치" 배지, 레벨업 가능하면(비용 충분, 상한 미만) 오른쪽 위에 초록 ▲ 배지
- 카드를 탭하면 상세로 간다(배치 선택 중이 아니면).

### 2.5 영웅 상세 (레벨업)

- 큰 카드:
  - 등급 보석, "칭호 이름", 등급 글자, 별
  - "Lv 12 / 40" 막대(면 분할 바)
- 능력치 표(HP, 공격, 공격 간격, 사거리, 전투력): 현재 값 옆에 다음 레벨 값을 초록 "→ 1,234 (+56)"으로 미리 보여 준다.
- 스킬 1·2: 수치가 들어간 설명(개정 10 템플릿)
- 설명문
- 하단 버튼:
  - **[레벨업]**: 비용(골드 아이콘·식량 아이콘 + 숫자)을 버튼 안에 둔다. 모자라거나 상한이면 비활성이고, 이유를 작게 표시한다("골드 부족", "최대 레벨").
  - **[×10]**: 최대 10레벨까지 감당 가능한 만큼. 버튼에 실제 횟수와 총비용을 보여 준다.
  - **[배치]**: 비어 있는 첫 슬롯에 넣거나, 이미 배치돼 있으면 "배치 중"
- 성공 연출: 카드에 로우폴리 빛 조각이 0.5초 퍼진다. 레벨 숫자가 튀어 오른다. 바뀐 능력치 숫자가 잠깐 초록으로 반짝인다.
- 좌우 화살표 또는 스와이프로 목록의 이전·다음 영웅으로 간다.
- [닫기]를 누르면 목록으로 돌아간다.

## 3. 피해량 숫자

- 화면 공간 Node2D 하나(hp_bars 방식)로 모든 숫자를 한 번에 그린다. 동시에 최대 80개이고, 넘치면 가장 오래된 것을 지운다.
- 표시:
  - 영웅이 몬스터에게: 흰색 숫자, 테두리 진하게, 크기 22
  - 치명타: 주황 28 + "!"
  - 스킬(aoe·chain·cleave): 노랑
  - 독: 초록 작은 숫자, 1초마다 합쳐서 하나
  - 몬스터가 영웅에게: 빨강 22
  - 회피: 회색 "회피"
  - 회복(heal_aura·lifesteal): 초록 "+N"(0이면 표시 안 함)
- 위치는 대상 HP 바 위다. 같은 대상의 연속 숫자는 좌우로 ±12px 흔들어 겹침을 줄인다. 0.8초 동안 32px 떠오르고, 마지막 40%에 사라진다. 치명타는 처음 0.1초 동안 1.3배에서 줄어든다.
- 숫자는 반올림한 정수다. 1000 이상은 "1.2k"로 쓴다.
- 성능: 숫자 문자열은 캐시한다(값 → 문자열). 그리기 호출은 숫자당 테두리 1 + 본문 1이다. 화면 밖은 건너뛴다.
